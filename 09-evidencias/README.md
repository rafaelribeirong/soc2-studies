# 09 — Evidências

Objetivo: aprender a provar que os controles existem e funcionam.

## Tipos de evidência

- Política
- Procedimento
- Configuração
- Screenshot
- Relatório
- Log
- Ticket
- Aprovação
- Registro
- População
- Amostra

## Pergunta central

**O controle apenas existe ou conseguimos provar que funcionou?**

Em Type II, a evidência deve suportar a operação do controle durante o período examinado.
