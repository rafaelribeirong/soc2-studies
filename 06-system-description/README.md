# 06 — System Description

Objetivo: aprender a estruturar a descrição do sistema usada em um SOC 2.

## Elementos de estudo

- Serviços
- Infraestrutura
- Software
- Pessoas
- Procedimentos
- Dados
- Limites do sistema
- Service Commitments
- System Requirements
- Terceiros
- Controles relevantes

A descrição deve representar de forma consistente o sistema que está sendo examinado.
