# 11 — Auditoria e Testes

Objetivo: entender como controles são testados em um SOC 2.

## Tópicos

- Design
- Implementation
- Operating Effectiveness
- Inquiry
- Inspection
- Observation
- Reperformance
- Configuração
- População
- Amostragem
- Exceções
- Deficiências

No Type II, o foco é a consistência da operação dos controles durante todo o período examinado.
