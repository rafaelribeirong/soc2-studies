# 10 — Readiness Assessment

Objetivo: desenvolver uma metodologia prática de readiness SOC 2.

## Fluxo

**Escopo → Critérios aplicáveis → Documentos → Entrevistas → Controles existentes → Evidências → Gaps → Plano de ação → Implementação → Coleta de evidências → Readiness → Auditoria**

## Princípio

Nunca considerar um item atendido apenas porque existe uma política.
