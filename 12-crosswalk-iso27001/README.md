# 12 — Crosswalk SOC 2 x ISO/IEC 27001

Objetivo: identificar oportunidades de reaproveitamento sem tratar SOC 2 como extensão da ISO 27001.

## Avaliar

- Controles reaproveitáveis
- Documentos reaproveitáveis
- Evidências reutilizáveis
- Controles que precisam ser ampliados
- Gaps específicos de SOC 2

O crosswalk é uma ferramenta de eficiência, não substitui a análise dos Trust Services Criteria.
