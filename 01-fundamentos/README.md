# 01 — Fundamentos

Objetivo: entender o que é SOC, a finalidade dos relatórios SOC e os principais participantes de um engagement.

## Tópicos

- O que é SOC
- SOC 1, SOC 2 e SOC 3
- Service Organization
- User Entity
- Service Auditor
- Management Assertion
- Attestation Engagement
- Uso e finalidade do relatório SOC 2
- [Por que o SOC 2 pode exigir esforço adicional em relação à ISO/IEC 27001](02-soc2-e-esforco-adicional.md)

## Resultado esperado

Ao concluir este módulo, deve ser possível explicar com clareza o que é um SOC 2, para quem ele serve, qual problema ele resolve e por que uma organização madura em ISO/IEC 27001 ainda pode precisar de preparação adicional para um SOC 2.
