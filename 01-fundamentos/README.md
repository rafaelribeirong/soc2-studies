# 01 — Fundamentos

Objetivo: entender o que é SOC, a finalidade dos relatórios SOC e os principais participantes de um engagement.

## Tópicos

- O que é SOC
- SOC 1, SOC 2 e SOC 3
- Service Organization
- User Entity
- Service Auditor
- Management Assertion
- Attestation Engagement
- Uso e finalidade do relatório SOC 2

## Resultado esperado

Ao concluir este módulo, deve ser possível explicar com clareza o que é um SOC 2, para quem ele serve e qual problema ele resolve.
