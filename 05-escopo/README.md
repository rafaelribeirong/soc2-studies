# 05 — Escopo

Objetivo: aprender a definir corretamente os limites de um SOC 2.

## Tópicos

- Serviços
- Sistemas
- Aplicações
- Infraestrutura
- Pessoas
- Processos
- Dados
- Locais
- Fornecedores e terceiros
- System Boundary
- Subservice Organizations
- Carve-Out Method
- Inclusive Method
- CUECs
- CSOCs

Um escopo mal definido compromete todo o restante do projeto.
