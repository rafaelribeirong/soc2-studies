# 04 — Categorias Adicionais

Além de Security, o SOC 2 pode abranger categorias adicionais.

## Categorias

- Availability
- Processing Integrity
- Confidentiality
- Privacy

## Objetivo

Entender quando cada categoria é aplicável, quais critérios adicionais entram no escopo e quais controles e evidências normalmente são necessários.
