# 07 — Gestão de Riscos

Objetivo: aplicar gestão de riscos ao contexto SOC 2.

## Fluxo de análise

**Ativo/Processo → Ameaça → Vulnerabilidade → Risco → Controle → Evidência**

## Tópicos

- Objetivos do sistema
- Identificação de riscos
- Avaliação de impacto e probabilidade
- Tratamento de riscos
- Riscos de fraude
- Mudanças significativas
- Riscos de terceiros

A ISO/IEC 27005 pode ser usada como apoio metodológico quando útil.
