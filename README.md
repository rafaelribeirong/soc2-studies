# SOC 2 Studies

Repositório de estudos técnicos e práticos sobre **SOC 2**, com foco em atuação profissional em projetos de **readiness, implementação, preparação para auditoria e acompanhamento de clientes**.

## Objetivo

Aprender SOC 2 de forma aplicada, desenvolvendo capacidade para conduzir um projeto completo:

**Diagnóstico → Escopo → Critérios → Riscos → Controles → Evidências → Gaps → Implementação → Readiness → Auditoria**

O foco não é apenas entender os critérios, mas saber transformar cada tema em trabalho de consultoria:

**Critério → Objetivo → Risco → Controle → Evidência → Teste → Gap → Ação corretiva**

## Trust Services Criteria

O estudo dos TSC será dividido em:

- CC1 — Control Environment
- CC2 — Communication and Information
- CC3 — Risk Assessment
- CC4 — Monitoring Activities
- CC5 — Control Activities
- CC6 — Logical and Physical Access Controls
- CC7 — System Operations
- CC8 — Change Management
- CC9 — Risk Mitigation

Categorias adicionais:

- Availability
- Processing Integrity
- Confidentiality
- Privacy

## Como cada critério será estudado

Para cada critério, o material deve responder:

1. O que o critério significa?
2. Qual objetivo ele busca atingir?
3. Qual risco ele trata?
4. Quais controles podem atendê-lo?
5. Quais evidências podem comprovar o controle?
6. Como um auditor pode testar o controle?
7. Quais gaps são comuns?
8. Como corrigir esses gaps?
9. Quais controles/evidências de ISO/IEC 27001 podem ser reaproveitados?

## Type I x Type II

O estudo dará atenção especial à diferença entre:

- **Design** — o controle foi desenhado adequadamente?
- **Implementation** — o controle foi implementado?
- **Operating Effectiveness** — o controle funcionou de forma consistente durante o período?

No Type II, a pergunta central será:

> O controle apenas existe ou conseguimos provar que funcionou durante todo o período auditado?

## Relação com ISO/IEC 27001

A ISO/IEC 27001 será usada como referência para reaproveitamento de controles, processos e evidências.

SOC 2 não será tratado como uma “ISO 27001 ampliada”.

O objetivo do crosswalk será identificar:

- controles reaproveitáveis;
- documentos reaproveitáveis;
- evidências reutilizáveis;
- controles que precisam ser ampliados;
- gaps específicos de SOC 2.
